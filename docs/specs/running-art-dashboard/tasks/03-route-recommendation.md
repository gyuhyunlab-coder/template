# 03 — 위치·수준 기반 경로 추천 (Kakao Maps API)

## Outcome

러닝 전, 선택된 프로필의 고정 홈 위치(또는 "내 위치 사용"으로 전환한 실제 브라우저 위치)를 출발점으로, 최근 5회 활동 평균 거리를 목표 삼은 추천 경로가 Kakao Maps 위에 그려져 보인다. 경로 자체는 특정 벤더의 길찾기 API가 아니라 직접 생성한 도형이며, 목표 거리가 짧으면 왕복 코스로 자동 대체된다.

## Blockers

01 (데모 프로필과 러닝 기록 확인) — 목표 거리 계산에 그 프로필의 최근 5회 활동 기록이 필요하다.

## Acceptance criteria

- [x] 추천 경로 화면에는 지도와 함께 목표 거리·예상 소요시간이 표시되며, 목표 거리는 선택된 프로필의 최근 5회 활동 평균 거리와 일치한다.
- [x] 목표 거리가 짧으면(1.2km 미만) 왕복(출발지→반환점→출발지) 코스가 대신 표시되고, 사용자가 루프와 왕복을 구분해서 알아볼 수 있다.
- [x] "내 위치 사용" 버튼을 누르면 브라우저 위치 권한 요청 후 추천 출발 위치가 실제 위치로 바뀌고, 권한을 거부하면 데모 고정 홈 위치가 유지된다.

## Constraints

- Kakao 지도 API 키(JavaScript 키)는 사용자가 직접 발급해 환경 변수(`NEXT_PUBLIC_KAKAO_MAP_APP_KEY`)로 제공하는 것을 전제로 한다. 키가 없을 때의 동작(안내 카드 표시)도 함께 처리한다. Kakao Developers에서 해당 키의 JavaScript SDK 도메인(로컬 개발은 `localhost`)을 등록해야 실제로 동작한다.
- 데모 프로필별 고정 홈 위치는 `data/seed/profiles.json`의 `home` 좌표를 사용한다.
- 경로 생성은 어떤 벤더의 길찾기 API도 쓰지 않는다. `lib/loop-route.ts`가 목표 거리에 맞춰 직접 도형을 생성하고, 지도는 표시 용도로만 Kakao Maps를 쓴다.
- 추천 경로 모양은 루프를 우선 생성하고, 목표 거리가 1.2km 미만으로 짧으면 왕복 코스로 대체한다(스펙의 확정된 제약). 자체 생성 도형이라 "생성 실패"는 없다 — 판단 기준은 API 응답 성공 여부가 아니라 목표 거리 자체다.

## Verification

- 최근 5회 활동 평균 거리 계산 로직에 대한 단위 테스트(시드 데이터의 프로필별 활동 이력 사용).
- 목표 거리 기준으로 루프/왕복을 결정하는 분기 로직에 대한 단위 테스트.
- 생성된 루프가 닫힌 도형이고(시작≈끝) 실제 경로 길이가 목표 거리에 근접하는지, 왕복 경로의 왕복 거리가 목표 거리와 일치하는지에 대한 단위 테스트(`lib/loop-route.test.ts`).
- "내 위치 사용" 권한 거부 시 데모 홈 위치로 폴백하는 단위 테스트.

## Review checkpoint
