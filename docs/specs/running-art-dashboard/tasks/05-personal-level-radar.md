# 05 — 개인화된 화면과 레벨 레이더 차트

## Outcome

대시보드는 항상 "나"의 데이터만 전면에 보여준다. 데모 프로필 전환은 접어 둔 보조 메뉴로 옮겨졌고, 예전의 "리더보드"(다른 사람 이름이 나란히 보이는 순위표)는 10살 단위+같은 성별의 익명 "비슷한 러너 평균"과 나를 비교하는 레이더 차트로 대체되었다. GPX 업로드 영역은 기본적으로 최근 활동이 이미 업로드 완료된 것처럼 보이는 확인 카드를 보여준다.

## Blockers

01 (데모 프로필과 러닝 기록 확인) — 레이더에 쓰일 내 기록·비교 그룹의 활동 데이터가 필요하다.

## Acceptance criteria

- [x] 화면 진입 시 다른 프로필의 이름이 나란히 보이지 않고, "나"로 선택된 프로필 한 명의 정체성만 드러난다. 전환 버튼을 눌러야 다른 데모 프로필 목록이 보이는 메뉴가 열린다.
- [x] "내 수준" 탭에는 지구력·스피드·꾸준함·효율·회복력 다섯 축의 레이더 차트가 보이고, "나"와 "비슷한 러너 평균" 두 겹으로 겹쳐 그려진다. 비교 대상의 실명은 어디에도 나타나지 않는다.
- [x] 비교 그룹은 선택된 프로필과 같은 10살 단위 연령대 + 같은 성별인 다른 프로필들이다.
- [x] 기록 탭의 업로드 영역은 최근 활동이 있으면 "최근 활동이 업로드되었습니다" 확인 카드를 기본으로 보여주고, 실제 파일 업로드는 보조 동작으로 계속 제공된다.

## Constraints

- 레이더 점수는 두 값(나, 비슷한 러너 평균) 중 더 나은 쪽을 100으로 놓고 비율로 환산한다. 페이스·심박수는 낮을수록 좋으므로 역수로 뒤집어 계산한다.
- 케이던스·심박수 데이터가 한쪽에 없으면 그 축은 50 대 50 중립으로 처리한다.
- 이전 태스크 04(연령대·성별 그룹 리더보드)는 이 태스크로 대체되어 `superseded` 처리했다.
