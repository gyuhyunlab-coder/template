# 러닝 데이터 아트 대시보드

서비스의 실제 브랜드명은 **STRIDE**다(화면 헤더 표시명). 이 스펙에서는 계속
"러닝 데이터 아트 대시보드"라는 설명적 이름으로 제품 개념을 지칭한다.

## 사용자에게 보이는 결과

- 사용자는 자신의 개인 대시보드로 들어가며, 화면은 항상 "나"의 데이터만 전면에 보여준다. 다른 사람의 이름이나 기록은 나란히 노출되지 않는다. 데모 프로필 10개 중 하나를 선택해 "나"로 볼 수 있지만, 전환은 접어 둔 메뉴 안에서만 이뤄진다.
- 러닝 전에는 선택한 프로필의 고정 홈 위치(또는 "내 위치 사용"으로 전환한 실제 브라우저 위치)를 기준으로, 최근 5회 활동의 평균 거리를 목표 삼은 추천 경로가 지도 위에 그려져 보인다.
- 러닝 후 GPX 파일을 업로드하면 별도 설정 없이 즉시 그 활동의 거리·소요시간·평균 페이스·케이던스·심박수가 보이고, 최장 거리·최고 평균 페이스 같은 개인 기록을 경신했는지 알 수 있다.
- 프로필이 업로드한 모든 경로가 지도 위에 반투명하게 겹쳐진 히트맵/아트 시각화로 누적되어 보인다.
- 10살 단위 + 성별이 같은 사람들의 기록과 내 기록을 견주어, 지구력·스피드·꾸준함·효율·회복력 다섯 축의 레이더 차트로 지금 내 수준을 한눈에 파악할 수 있다. 비교 대상은 이름 없는 "비슷한 러너 평균"으로만 나타난다.

## 승인된 범위

1. 데모 프로필 전환 (실 계정/로그인 없음, 화면 전면에는 "나" 한 명만 드러나고 전환은 보조 메뉴에 접혀 있음)
2. GPX 업로드·파싱을 통한 활동 기록 표시와 개인 기록(PR) 판정 (업로드 영역은 최근 활동이 이미 업로드 완료된 상태를 기본으로 보여준다)
3. 프로필 본인의 누적 경로 히트맵/아트 시각화
4. Kakao Maps API 기반 경로 추천 (실제 도로망 API 없이 직접 생성한 루프 우선, 목표 거리가 짧으면 왕복 코스)
5. 10살 단위 + 성별이 같은 익명 그룹 평균과 나를 비교하는 레벨 레이더 차트

## 관찰 가능한 수용 기준

- 화면 진입 시 "나"로 선택된 프로필 한 명의 정체성만 드러나고, 보조 전환 메뉴를 열었을 때만 다른 데모 프로필 목록이 보인다. 하나를 선택하면 그 프로필의 데이터로 전체 화면이 갱신된다.
- 추천 경로 화면에는 지도와 함께 목표 거리, 예상 소요시간이 표시되며, 목표 거리는 그 프로필의 최근 5회 활동 평균 거리와 일치한다.
- 목표 거리가 짧으면(1.2km 미만) 화면에 왕복(출발지→반환점→출발지) 코스가 대신 표시되고, 사용자가 루프와 왕복을 구분해서 알아볼 수 있다.
- "내 위치 사용" 버튼을 누르면 브라우저 위치 권한 요청 후, 추천 출발 위치가 실제 위치로 바뀐다. 권한을 거부하면 데모 고정 홈 위치로 유지된다.
- GPX 파일을 업로드하면 파싱 성공 시 해당 활동이 기록 목록과 히트맵에 즉시 반영된다.
- 업로드한 파일이 유효한 GPX가 아니면 오류 메시지가 보이고, 기존 기록은 변하지 않는다.
- 어떤 활동이 그 프로필의 최장 거리 또는 최고 평균 페이스를 경신하면, 기록 확인 화면에 "신기록" 표시가 보인다.
- 히트맵 화면에는 현재 선택된 프로필이 업로드한 경로만 겹쳐 보이고, 다른 프로필의 경로는 섞이지 않는다.
- 내 수준 화면의 레이더 차트는 선택된 프로필과 같은 10살 단위 연령대 + 같은 성별인 다른 프로필들의 평균과만 비교하며, 그 평균은 이름 없이 "비슷한 러너 평균"으로만 표시된다.
- GPX 업로드 영역은 기본적으로 가장 최근 활동이 이미 업로드 완료된 것처럼 보이는 확인 카드를 보여주고, 추가 업로드는 보조 동작으로 제공된다.

## 확정된 제약과 근거

- 인증 없이 데모 프로필 전환으로 시작한다. 가상 데이터가 10명 분량으로 설계되고, 레벨 레이더도 이 10명 사이에서 먼저 검증하면 되므로 실 계정 시스템은 지금 필수가 아니다.
- 활동 파일 형식은 GPX 단일로 통일한다. 히트맵/아트 시각화에는 위치 트랙(경도·위도)이 반드시 있어야 하는데, Garmin/Strava의 요약 CSV export에는 이 트랙이 없고 거리·시간·페이스 요약만 있다.
- 추천 경로의 목표 거리는 최근 5회 활동의 평균 거리로 계산한다.
- 추천 경로는 Kakao Maps API의 지도 위에 표시하되, 경로 자체는 특정 벤더의 길찾기 API에 의존하지 않고 직접 생성한 도형이다(합성 시드 데이터의 히트맵 경로를 만들 때 쓴 것과 같은 방식). 도로망 API 없이도 항상 목표 거리에 가깝게 만들어지고, 지도 표시 벤더를 나중에 바꾸더라도(실제로 Google→Naver→Kakao로 세 차례 바뀌었다) 경로 생성 로직은 그대로 재사용할 수 있다. 도형은 매끈한 곡선이 아니라 직선 변과 90도 코너로 이뤄진 직사각형 블록 루프다(실제 도로가 직선 구간과 코너로 이뤄진다는 점을 흉내 낸 것) — 목표 거리를 둘레로 보고 만들며, 목표 거리가 1.2km 미만으로 짧아 루프 모양이 부자연스러울 때만 왕복 코스로 대체한다. 같은 프로필의 시드 활동들은 같은 방향(bearingDeg)의 블록을 공유하도록 만들어, 여러 런이 실제 거리처럼 겹치는 구간이 생기게 한다.
- 추천 경로의 출발 위치는 프로필별 고정 홈 위치를 기본으로 하고, "내 위치 사용"으로 실제 브라우저 위치로 전환할 수 있게 한다. 매번 실제 위치 권한을 요구하면 합성 데이터의 도시와 다른 위치가 나와 추천이 엉뚱해질 수 있다.

## 가정

- 레벨 레이더의 축은 지구력(평균 거리)·스피드(평균 페이스, 낮을수록 좋음)·꾸준함(주당 러닝 횟수)·효율(평균 케이던스)·회복력(평균 심박수, 낮을수록 좋음) 다섯 가지로 시작한다.
- 개인 기록(PR) 판정 카테고리는 최장 거리와 최고 평균 페이스 두 가지로 시작한다.
- 히트맵은 프로필 본인의 누적 경로만 보여주며, 다른 프로필과 합산한 뷰는 없다.
- 유효하지 않은 GPX 업로드는 오류 메시지를 보여주고 무시하며, 기존 기록에는 영향을 주지 않는다.

## 범위 밖 (이유)

- 실제 회원가입/로그인/계정 시스템: 데모 프로필 전환으로 대체하며, 실 계정 시스템은 PRODUCT.md에서도 향후 로드맵으로 남겨두었다.
- Garmin/Strava 계정 실시간 연동(OAuth): PRODUCT.md에서 미정으로 남긴 항목이다.
- 결제/유료화: PRODUCT.md에서 범위 밖으로 확정했다.
- 러닝 중 실시간 GPS 트래킹: 완료된 활동을 업로드하는 방식만 지원한다.

## 보류된 사항

- 가상(합성) 러닝 데이터 10명 분량(서울, 최근 3개월, 주 3~4회 기준 약 400~500건) 생성은 이 스펙 확정 이후 별도로 진행하기로 했다.
- 실제 Kakao Maps API 키 발급과 연동 설정은 구현 단계에서 진행한다.

## 남은 위험

- 추천 경로는 실제 도로망 API 없이 직접 생성한 도형이라 항상 목표 거리에 가깝게 만들어지지만, 실제 도로망 데이터를 참조하지 않으므로 실제 카카오 지도의 특정 도로·골목과 정확히 겹친다는 보장은 없다. 다만 직선 변 + 90도 코너로 이뤄진 블록 형태로 바꿔(구 버전의 매끈한 곡선보다) 실제로 뛸만한 모양에 훨씬 가까워졌고, 이전처럼 하천을 대각선으로 가로지르는 부자연스러운 구간은 사라졌다.
- GPX 파일에 케이던스·심박 확장 필드가 없는 경우, 해당 항목은 표시하지 않는다.
- 데모 데이터가 10명뿐이라 10살 단위 + 성별 그룹 중 일부 구간은 비교 대상이 1~2명뿐이라 "비슷한 러너 평균"의 표본이 작다.
- 같은 그룹 안의 프로필들이 애초에 비슷한 페이스·거리로 설계된 경우(예: 20대 여성 그룹), 레이더 차트에서 나와 그룹 평균의 차이가 거의 드러나지 않을 수 있다. 이는 버그가 아니라 시드 데이터의 특성이다.
